# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email `support@notilify.com` with:

- the affected SDK and version
- reproduction steps or a proof of concept
- the potential impact
- any suggested mitigation

Avoid including real API keys, recipient phone numbers, or production message data. The maintainers will acknowledge the report and coordinate remediation and disclosure privately.

## Supported versions

Before the first stable release, only the latest published `0.x` version of each SDK will receive security fixes. This policy will be updated when stable release lines exist.
